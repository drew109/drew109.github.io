Stealth PowerShell Payload Loader

This script is designed as a stealthy and automated payload execution framework using PowerShell. Delivered via HID (e.g., Rubber Ducky or Flipper Zero), it opens a PowerShell session, establishes a secure TLS connection, and downloads a Base64-encoded binary from a remote source.

Once retrieved, the encoded payload is decoded into an executable file with a randomized name and stored in the temporary directory. The script then silently executes the payload using Start-Process with a hidden window and waits for execution to complete.

It performs cleanup by removing both the payload and any generated artifacts from disk, avoiding detection by not writing PowerShell scripts to disk. This modular approach allows the operator to run any executable payload remotely, making it flexible for red team engagements or sandbox bypass.
