PowerShell Execution Detection Lab

This project was built in a controlled Windows lab to study how PowerShell-driven execution chains behave on an endpoint and what kinds of activity defenders can monitor during execution.

Working through the lab helped me understand encoded content handling, process spawning, temporary-file behavior, and how common automation patterns create host-level signals that can be useful for detection and investigation.

The public write-up is intentionally kept high level. I keep implementation details private and focus the portfolio version on the defensive takeaway: better intuition around Windows scripting activity, endpoint visibility, and security-minded analysis in an authorized lab setting.
